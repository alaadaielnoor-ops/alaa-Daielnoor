# المكتبة الجغرافية والتربوية الذكية

تطبيق ويب تقدمي (PWA) متكامل مصمم باللغة العربية وموجه لمعلمي الجغرافيا والدراسات الاجتماعية، يتيح جمع الكتب المدرسية، وأدلة المعلم، والأطالس، والمراجع في مستودع مركزي، وفهرستها نصياً ودلالياً، واستخراج نصوصها عبر تقنيات التعرف الضوئي (OCR)، والاستفادة منها في توليد الخطط الدراسية، وأوراق العمل، والاختبارات التحصيلية الموثقة بأرقام الصفحات.

---

## 🌟 أبرز ميزات النظام المنفذة فعلياً

1. **لوحة التحكم والإحصاءات الحية (Dashboard)**:
   - إحصاءات فعلية مرتبطة بقاعدة البيانات: إجمالي الكتب، الملفات، الدروس، أوراق العمل، الاختبارات، والمساحة التخزينية.
   - رصد حالة معالجة الملفات والمهام المكتملة أو المتعثرة.
   - حالة النسخ الاحتياطي وإمكانية النسخ الفوري بضغطة زر.

2. **المكتبة الرقمية وإدارة المستندات**:
   - دعم صيغ متعددة: PDF وDOCX وPPTX وTXT والصور والروابط الخارجية.
   - رفع ملفات فردية ومتعددة مع شريط تقدم فعلي.
   - اكتشاف وتفادي الملفات المكررة آلياً باستخدام البصمة الرقمية (SHA-256).
   - قارئ مستندات مدمج يعرض صفحات الملف، مع التمييز بين رقم صفحة الملف والرقم المطبوع في الكتاب (`ص X`).
   - تنزيل الملف الأصلي، التعديل على البيانات الوصفية، الأرشفة، وسلة المهملات.

3. **التصنيف التربوي الديناميكي (Taxonomy)**:
   - هيكل تدريسي كامل للمواد، المراحل، الصفوف، الفصول، الوحدات، والدروس، قابل للتعديل والإضافة من الواجهة دون تعديل في الكود.

4. **معالجة المستندات واستخراج النصوص وOCR**:
   - خط معالجة خلفي كامل يستخرج النصوص صفحة بصفحة، مع مراعاة اتجاه النص العربي، التشكيل، وتوحيد الهمزات.
   - تقنية OCR للصفحات المصورة أو الممسوحة ضوئياً مع مؤشر نسبة الثقة.
   - تقسيم النصوص إلى مقاطع دلالية (Chunks) بحدود 400-600 حرف وربطها بالمصدر والصفحة والمادة.

5. **البحث الهجين والدلالي (Hybrid & Semantic Search)**:
   - بحث بالكلمات، العبارات، وبالمعنى الدلالي.
   - تحديد نطاق البحث: في المكتبة كاملة أو داخل كتب محددة يختارها المعلم.
   - إظهار المقتطفات المطابقة مبرزة (Highlighted)، ودرجة الصلة، ورقم الصفحة، وزر للانتقال المباشر للمصدر.
   - عمليات بحث مفضلة ونموذجية سريعة.

6. **المساعد التربوي الذكي المستند للمكتبة (RAG)**:
   - مساعد محادثة عربي ذكي مدعوم بنموذج `gemini-3.8-flash`.
   - استرجاع دقيق من نصوص الكتب قبل الإجابة، مع إرفاق شواهد صريحة: `[اسم الكتاب، ص X]`.
   - الامتناع عن اختراع مراجع أو أرقام صفحات في حال عدم توفر المعلومة في المكتبة.
   - عزل نصوص المستخدم كبيانات غير موثوقة لمنع حقن الأوامر (Prompt Injection Defense).
   - إمكانية حصر إجابات المساعد في كتاب معين (مثل كتاب الطالب أو دليل المعلم).

7. **استوديو إعداد الدروس النموذجية (Lesson Studio)**:
   - محرر كامل لخطة الدرس: الأهداف (معرفية، وجدانية، مهارية)، المفاهيم، التهيئة الحافزة، خطوات التنفيذ وأنشطة المعلم والمتعلم، استراتيجيات التدريس، الفروق الفردية، التكليف المنزلي، والصفحات المعتمدة.
   - توليد خطة درس متكاملة بالذكاء الاصطناعي مع إمكانية تعديل جميع الحقول وحفظها وطباعتها.

8. **استوديو الأنشطة وأوراق العمل (Worksheet Studio)**:
   - توليد أوراق عمل متدرجة الصعوبة (مبتدئ، متوسط، متقدم).
   - دعم أنشطة متنوعة: فردية، تعاونية، تفكير ناقد، وتطبيقات خرائط صماء.
   - تنسيق مخصص للطباعة وتوزيعها على الطلاب.

9. **استوديو الاختبارات والتقويم (Assessment Studio)**:
   - دعم أسئلة متنوعة: اختيار من متعدد، صح وخطأ، إكمال، تفسير خريطة كنتورية، أسئلة مقالية، وتحليل بيانات.
   - مفتاح إجابة مستقل مع التعليل العلمي المستند للكتاب، وجدول توزيع الدرجات (Rubric).

10. **العروض التقديمية والملخصات (Presentation Studio)**:
    - عروض شرائح تفاعلية مع بطاقات المفاهيم، وتوجيهات وملاحظات المعلم للشرح الصفي.

11. **مركز الخرائط والجغرافيا**:
    - مستودع خرائط طبيعية، سياسية، طبوغرافية، مرئيات أقمار صناعية، ورسوم بيانية مناخية (Climatograms).
    - حفظ الإحداثيات، المقياس، المسقط، والتطبيقات التدريسية المقترحة.

12. **المصادر والمراجع الخارجية**:
    - دليل روابط البوابات الجيولوجية والأكاديمية مع مؤشرات الموثوقية وملاحظات المعلم.

13. **العمل دون اتصال والمزامنة (PWA & Offline Sync)**:
    - تطبيق PWA قابل للتثبيت مع Service Worker وتخزين مؤقت.
    - قاعدة بيانات محلية (IndexedDB) تتيح تصفح الكتب والخطط والأنشطة دون اتصال بالإنترنت.
    - طابور مزامنة محلي (Sync Queue) يسجل التعديلات التي تمت أثناء غياب الشبكة ومزامنتها تلقائياً فور عودة الاتصال.

14. **النسخ الاحتياطي والاستعادة الأكيدة**:
    - إنشاء نسخ احتياطية كاملة تتضمن كافة الجداول والمصادر بضغطة زر.
    - حساب بصمة رقمية أمنية (SHA-256 Checksum) لكل نسخة.
    - آلية استعادة حقيقية تم اختبارها بنجاح مع التحقق من سلامة البصمة ومطابقة الهيكل.
    - تصدير البيانات الوصفية بصيغتي CSV (متوافق مع Excel) و JSON.

15. **الأمان والصلاحيات وسجل التدقيق**:
    - نموذج تحكم بالوصول مستند للأدوار (RBAC): مدير نظام (Admin)، معلم ومؤلف (Teacher)، مطلع وزائر (Viewer).
    - سجل تدقيق تفصيلي (Audit Logs) يرصد كافة العمليات الحساسة (إنشاء، تعديل، حذف، أرشفة، استعادة، ونسخ احتياطي).

## 🛠️ البنية التقنية والتشغيل

- **الواجهة الأمامية**: React 19، TypeScript، Tailwind CSS 4، Lucide Icons، Framer Motion.
- **الخادم والواجهة الخلفية**: Node.js + Express مع Vite Middlewares (`server.ts`).
- **المعالجة واستخراج النصوص**: خط معالجة محلي مستند إلى فك ترميز النصوص العربية وتطبيع الهمزات والتشكيل، مع دعم Gemini Multimodal OCR.
- **الذكاء الاصطناعي**: حزمة `@google/genai` الرسمية بنموذج `gemini-3.8-flash` وتطبيق بروتوكول RAG المنضبط.
- **التخزين المحلي والقاعدة**: محرك علائقي ثابت على القرص مع مطابقة لمخطط PostgreSQL (`database_schema.sql`) وقاعدة عميل `IndexedDB`.

### 🚀 خطوات التشغيل

1. **تثبيت الاعتماديات**:
   ```bash
   npm install
   ```

2. **تهيئة متغيرات البيئة**:
   قم بنسخ ملف `.env.example` إلى `.env` واضبط مفتاح Gemini API:
   ```env
   GEMINI_API_KEY="your-gemini-api-key"
   PORT=3000
   ```
   *(ملاحظة: في بيئة Google AI Studio، يتم حقن المفتاح تلقائياً من لوحة الأسرار Secrets)*.

3. **تشغيل الخادم والتطبيق**:
   ```bash
   npm run dev
   ```
   سيتم تشغيل التطبيق على المنفذ `3000` (http://localhost:3000).

4. **تشغيل الاختبارات الآلية**:
   ```bash
   npx tsx scripts/test-system.js
   ```

## 📱 التثبيت على الهاتف والكمبيوتر (PWA)

- **على الكمبيوتر (Chrome / Edge / Windows / Mac)**:
  اضغط على زر **"تثبيت كـ تطبيق (PWA)"** الظاهر في أعلى الشريط العلوي، أو اضغط على أيقونة التثبيت في شريط العنوان بالمتصفح.
- **على أجهزة iPhone / iPad (Safari)**:
  اضغط على زر المشاركة (Share) في أسفل المتصفح، ثم اختر **"إضافة إلى الصفحة الرئيسية (Add to Home Screen)"**.
- **على أجهزة Android (Chrome)**:
  ستظهر رسالة التثبيت تلقائياً، أو اضغط على زر التثبيت في شريط التطبيق.

## 🔒 سياسات الأمان والخصوصية

- عدم تسريب أو تضمين مفاتيح API في كود المتصفح؛ كافة الاتصالات بالذكاء الاصطناعي تتم عبر نقاط النهاية الآمنة على الخادم `/api/*`.
- عزل مستندات المستخدمين والتحقق من حجم ونوع الملفات قبل الحفظ.
- التحقق التلقائي من البصمة الرقمية (SHA-256) لمنع التكرار وضمان سلامة النسخ الاحتياطية.
- تسجيل كل عملية تعديل أو حذف في جدول `audit_logs` لضمان الشفافية وقابلية التدقيق.
